# Demo Script (4 minutes)

Rehearse out loud, as a team, at least twice. Confidence beats slides.

## Before you walk in

- [ ] App open in a fresh tab at `/` — **Demo Mode is offline-safe**, it never
      calls OCR or the network for the two presets.
- [ ] Second tab on `/pitch` with the deck ready, one tab on `/history`.
- [ ] Phone hotspot as backup network.
- [ ] Screen brightness up, notifications off, zoom at 100%.

## Timeline

| Time | Screen | What you say |
| --- | --- | --- |
| 0:00 | Home | "Every packaged product in India must carry 7 declarations under Rule 6. Today an officer checks them by hand, one product a minute." |
| 0:30 | Scan → **Try a Demo** → non-compliant preset | "This is a real snack pack. Watch." |
| 0:50 | Report | "Verdict: NON-COMPLIANT. Four mandatory declarations missing — each with the exact sub-rule cited." |
| 1:20 | Expand raw text | "Not a black box — here's the raw extraction and the per-field confidence." |
| 1:40 | Edit a field | "An officer can correct a misread before finalising. Human in the loop." |
| 2:10 | Demo → compliant preset | "Same engine, a fully compliant pack — all 7 green." |
| 2:30 | History | "Every inspection is logged, filterable, auditable." |
| 2:50 | How it works | "Image → OCR → rule engine → cited report. Rules are data, so new declarations plug in." |
| 3:10 | Pitch | Impact + roadmap: regional languages, batch API for e-commerce, officer logins. |
| 3:40 | — | Close: "Scalable, transparent, and legally grounded enforcement." |

## Fallbacks

- **No internet:** stay entirely in Demo Mode — both presets are hardcoded.
- **Live upload misreads:** that's the point — show the confidence drop and the
  manual correction flow.
- **App won't load:** present from the PDF deck in `/mnt/documents`.

## Deck to-do before judging

- Add a real screenshot of a non-compliant report to slide 3 or 5.
  "Here's it actually working" beats any description.
